# SHADOW KOMBAT

A 2D fighting game inspired by Mortal Kombat, built with pure HTML/CSS/JavaScript.

## Features

- Two original characters: ARYA (Shadow Assassin) and TAKEN (Crimson Hunter)
- Dark, atmospheric arena with fire braziers and ember particles
- Full combat system: Punch, Kick, Block, and Special Moves
- Mobile-friendly: On-screen D-Pad and action buttons
- Desktop support: Keyboard controls (WASD + J/K/L/I)
- Round-based gameplay: Best of 3 rounds
- AI opponent with adaptive behavior
- Visual effects: Hit sparks, blood, screen shake, slow-motion

## How to Play

### On Mobile
- D-Pad: Move (left/right), Jump (up), Crouch (down)
- Action Buttons: Punch, Kick, Block, Special

### On Desktop
- WASD / Arrow Keys: Move, Jump, Crouch
- J: Punch | K: Kick | L: Block | I: Special | Esc: Pause

## Quick Start

1. Download shadow_kombat.html
2. Open it in any modern browser (Chrome, Safari, Firefox)
3. Tap "Enter The Arena" to begin

## Game Flow

1. Title Screen -> Tap "Enter The Arena"
2. Character Select -> Choose ARYA or TAKEN
3. VS Screen -> Cinematic intro
4. Battle -> Best of 3 rounds
5. Victory/Defeat -> Rematch or return to menu

## Characters

### ARYA - Shadow Assassin
- Fighting Style: Street / Tactical
- Special Move: Shadow Dash (teleport behind opponent)
- Stats: High speed, balanced power

### TAKEN - Crimson Hunter
- Fighting Style: Grappler / Rushdown
- Special Move: Crimson Tackle (charging attack)
- Stats: High strength, slower

Built with HTML5 Canvas, vanilla JavaScript, and CSS3.
